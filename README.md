# 《行政诉讼法》（第三版，何海波）案件索引

本仓库整理《行政诉讼法》（第三版，何海波著）书末《案例索引》中收录的全部案件条目，供检索与研究使用。

## 数据概览

| 类别 | 条目数 |
| --- | --- |
| （一）中国法院诉讼案例 | 614 |
| （二）非诉执行案件 | 8 |
| （三）清末民国案例 | 4 |
| （四）外国法院与国际机构案例 | 9 |
| **合计** | **635** |

原书编号说明（据原书《说明》）：

1. 案件当事人使用缩略语，按原告（申请人）的字母顺序排列；原告为企业的，按原告字号的字母顺序排列。非诉执行案件、清末民国案例、外国法院和国际机构的案例单列于后。
2. 原告为企业的，名称一般只写"地名＋字号＋行业＋公司"。
3. 行政机关名称采用约定俗成的缩写，标明地域。

## 数据来源与生成方法

1. 原书末尾《案例索引》位于原书第 736–756 页（对应 PDF 第 763–783 页）。
2. 该书为扫描 PDF，正文无可提取文本层，故使用 macOS Vision 框架（`zh-Hans`，Accurate 模式）进行 OCR，并借助识别结果的坐标信息还原多行/换行排版。
3. 按原书《说明》的编排规则将条目结构化为上述字段。
4. 原始 OCR 文本一并保留于 `raw/`，便于回溯核对。

## 已知局限

- OCR 对少数人名、地名可能产生形近字错误（如"颍上/颖上""茌平/在平""酉阳/西阳"等），已对可确认者做了校正，仍可能存在个别遗漏。
- 原书页码为原书正文页码，非 PDF 页码（二者相差 27 页）。
- 本仓库仅收录**书目索引信息**（案件名称与页码），**不包含**判决书全文。如需判决书全文，可前往下列数据库检索案件名称：
  - 北大法宝：https://www.pkulaw.com
  - 中国裁判文书网：https://wenshu.court.gov.cn
  - 无讼案例：https://www.itslaw.com
