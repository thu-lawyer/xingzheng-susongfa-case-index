# 《行政诉讼法》（第三版，何海波）案件索引与判例检索

本仓库整理《行政诉讼法》（第三版，何海波著）书末《案例索引》收录的全部案件，并附在北大法宝检索到的对应裁判文书全文。

## 数据概览

| 项目 | 数量 |
| --- | --- |
| 案件条目总数 | 635 |
| 检索到对应裁判文书 | 435 |
| 已取得判决书全文 | 435 |

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `cases.md` | 书末《案例索引》，按原书分类与字母顺序 |
| `data/cases.csv` / `data/cases.json` | 案件索引结构化数据 |
| `data/pkulaw_results.json` | 每案检索命中情况、最佳匹配标题、匹配分、是否取得全文 |
| `data/judgments.jsonl` | **判决书全文**，一行一个案件（JSON Lines） |
| `raw/case_index_ocr.txt` | 原书索引页 OCR 原文 |

### judgments.jsonl 字段

`case_name` 书中案件名 ｜ `category` 原书分类 ｜ `book_pages` 原书页码 ｜ `matched_title` 匹配到的文书标题 ｜ `pkulaw_url` 法宝链接 ｜ `doc_type` 文书类型/法院/案号/日期 ｜ `match_score` 匹配分 ｜ `fulltext` 判决书全文。

## 数据来源与生成方法

1. **案件索引**：原书《案例索引》在原书第 736–756 页（PDF 第 763–783 页）。该书为扫描版 PDF 无文本层，使用 macOS Vision（zh-Hans，Accurate）OCR，并依据坐标还原多栏/换行排版。
2. **判决书全文**：通过本机 Chrome（CDP 自动化）访问北大法宝司法案例库。采用标题检索；匹配规则为原告名完整出现在标题中，或与标题最长公共子串≥4 字，且结果须为行政案件。文书详情必须经由检索结果点击进入。
3. 抓取全程限速。

## 已知局限

- 书中案件名为索引缩略名，与裁判文书正式标题常有差异；部分案件（多为年代较早或未公开者）未能匹配。
- 少数结果可能仍为同名当事人的其他案件，`match_score` 与 `matched_title` 可供复核。
- OCR 存在个别形近字误差可能。
- 原书页码为原书正文页码，非 PDF 页码。
